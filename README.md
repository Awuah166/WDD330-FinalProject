# Real Estate Finder

## Overview

Real Estate Finder is a responsive web application that helps users discover, explore, and save real estate listings. The application allows users to search for properties, view detailed property information, filter results based on preferences, and save favorite properties for future reference.

This project was developed as a final project for WDD330: Web Frontend Development and demonstrates the use of HTML, CSS, and vanilla JavaScript, along with external APIs, local storage, ES modules, responsive design, and dynamic content rendering.

---

## Features

### Property Search

Search for available properties using keywords, location, or property type.

### Property Listings

View a collection of available properties with images, pricing, and key details.

### Property Details

View detailed information about a selected property, including description, location, amenities, and images.

### Advanced Filtering

Filter properties based on:

* Price range
* Property type
* Number of bedrooms
* Number of bathrooms

### Interactive Maps

View property locations using a mapping service.

### Favorites

Save and manage favorite properties using browser local storage.

### Responsive Design

Optimized experience for desktop, tablet, and mobile devices.

### Dynamic Content

Property listings and details are generated dynamically using JavaScript and external APIs.

### CSS Animations

Interactive animations improve user experience and visual feedback.

## Installation and Usage

1. Clone the repository.

```bash

```

2. Navigate to the project folder.

```bash
cd real-estate-finder
```

3. Open the project using a local development server.

4. Configure API keys if required.

5. Launch the application in a web browser.
